Service Timer — Extensão Chrome MV3

Service Timer MV3

Extensão Chrome para controle de tempo por serviço, com ferramentas de produtividade para edição de conteúdo em plataformas LMS e rich text editors.

⏱Cronômetro

O painel lateral fica sempre visível enquanto você trabalha em outras abas, permitindo controlar o tempo sem interromper o fluxo de trabalho.

▶ Iniciar
Captura a URL da aba ativa e inicia o contador. O ícone da extensão fica verde.
⏸ Pausar / Retomar
Registra o horário de pausa e retorno automaticamente. O ícone fica laranja durante a pausa.
⏹ Finalizar
Abre o modal de comentário, salva o registro e exibe o resumo com duração total.
📌 Suspender
Pausa sem finalizar. O card fica na lista de suspensos e pode ser retomado a qualquer momento.
Múltiplos cards podem ficar suspensos simultaneamente. Para retomar um card suspenso, o atendimento atual deve estar finalizado ou suspenso primeiro.

O cronômetro também pausa automaticamente quando todas as janelas do Chrome são fechadas, registrando o horário de pausa no histórico do card.

Cada atendimento finalizado gera um registro completo:

Início / FimHorários no formato HH:MM:SS

Os últimos 3 registros aparecem direto na tela principal. O histórico completo fica em Ver todos, onde é possível deletar registros individualmente.

🏷Tipos de serviço

A lista de tipos é totalmente editável. Acesse pelo botão ✎ ao lado do combo.

  • Adicionar novos tipos pelo campo de texto inferior
  • Reordenar com as setas ↑ ↓
  • Remover com o botão ✕
  • O tipo pode ser alterado enquanto o cronômetro está rodando

🔗Links

Links do atendimento

A URL da aba ativa é capturada automaticamente ao iniciar. Links extras podem ser adicionados durante o atendimento com o botão ＋ Adicionar.

Links salvos

Favoritos com rótulo e URL, acessíveis em Configurações → Links salvos. Clique no link para abrir em nova aba.

Starters

Links marcados com ⭐ como starter podem ser abertos todos de uma vez pelo botão 🚀 Abrir links do dia na tela principal — útil para abrir todas as ferramentas de trabalho com um clique.

📊Google Sheets

Ativar a integração

Use o toggle Google Sheets na tela principal para habilitar a seção:

  • Sem URL configurada → aparece um campo para digitar e salvar a URL diretamente na tela principal
  • Com URL configurada → aparece o botão 📊 Enviar ao Google Sheets

Como funciona o envio

Os registros pendentes são enviados para o Google Apps Script, que:

  1. Busca ou cria automaticamente uma aba chamada "Service Timer" na planilha
  2. Cria cabeçalhos com fundo verde e linha congelada na primeira execução
  3. Verifica os IDs já existentes para evitar duplicatas
  4. Adiciona os registros novos como novas linhas

Configurar o Apps Script

  1. Abra a planilha desejada no Google Sheets
  2. Clique em Extensões › Apps Script
  3. Apague o código existente e cole o script de Configurações → Ver script do Apps Script
  4. Salve e clique em Implantar › Nova implantação
  5. Tipo: App da Web · Acesso: Qualquer pessoa
  6. Copie a URL gerada e cole em Configurações ou diretamente na tela principal

🎓Canvas LMS

Quando o painel lateral está aberto em uma aba de curso do Canvas (/courses/XXXX/), a seção 🎓 Canvas LMS aparece automaticamente com o ID do curso detectado.

Funciona com a sessão ativa do Canvas — não requer token de API. A autenticação é feita pelos cookies de sessão do navegador.

Aplicar recuo nos módulos

O botão 🔧 Aplicar recuo nos módulos percorre todos os módulos do curso e aplica a indentação automaticamente:

ItemRecuo aplicado
Nome contém algum termo da lista de exceçõesindent: 0 — fica como cabeçalho
Todos os demais itensindent: 1 — recuado

Configurar as exceções

Em Configurações → Canvas LMS → Páginas sem recuo, adicione um nome parcial por linha:

Orientação do professor
Material complementar
Apresentação
Objetivos

A comparação é parcial e sem diferenciação de maiúsculas. Ao digitar Orientação do professor, a extensão reconhece automaticamente:

  • Unidade 1 Orientação do professor
  • Unidade 2 Orientação do professor
  • Unidade 3 Orientação do professor

A função só faz chamadas PUT nos itens que precisam ser alterados. Ao concluir:

✅ 34 item(s) ajustado(s) em 5 módulo(s) · 60 total

✨Copia Inteligente

Ferramenta de cópia avançada para colar conteúdo em editores rich text como Canvas LMS, TinyMCE, CKEditor, Moodle e Bubble.io sem deixar lixo de HTML.

O que ela faz

🔤 Corrige mojibake
Detecta e corrige textos com encoding quebrado: JoÃ£o → João
🧹 Remove lixo HTML
Elimina class, id, style, data-*, scripts, iframes e tags vazias
🎨 Cor padronizada
Força #333333 em todos os parágrafos e listas, independente da cor original
📋 Lista unificada
Converte listas numeradas <ol> em listas com bullets <ul>
👁 Remove ocultos
Ignora elementos com display:none ou visibility:hidden
📝 Tags essenciais
Mantém apenas: <p> <br> <strong> <em> <ul> <li>

HTML gerado

Ao clicar em "Ver HTML" no editor após colar, o código estará assim:

<p style="color:#333333;">Texto com <strong>negrito</strong> e <em>itálico</em>.</p>

<ul style="color:#333333;">
<li>Primeiro item</li>
<li>Segundo item</li>
</ul>
Ao copiar, nenhum HTML fica visível. O conteúdo entra no clipboard nos dois formatos: text/html (para editores rich text) e text/plain (para campos de texto simples).

Como usar

  1. Selecione o texto na página
  2. Clique com o botão direito
  3. Escolha ✨ Copia Inteligente (para editores)
  4. Cole normalmente no editor com Ctrl+V

🧪Teste de Clipboard

Acessível em Configurações → Ferramentas → Teste de Clipboard. Abre uma página de diagnóstico com dois painéis:

PainelFunção
Esquerda — RenderizadoÁrea de colagem com fundo branco e texto #333333, simulando como o conteúdo aparecerá num editor real. Texto justificado.
Direita — HTML resultanteExibe em tempo real o código HTML bruto que chegou no clipboard, para verificar se está limpo e sem lixo

Use para validar o resultado da Copia Inteligente antes de colar no Canvas ou outro editor.

📦Instalação

  1. Clone ou baixe o repositório
  2. Abra o Chrome e acesse chrome://extensions
  3. Ative o Modo do desenvolvedor (canto superior direito)
  4. Clique em Carregar sem compactação e selecione a pasta do projeto
  5. Clique no ícone da extensão → Abrir painel lateral
