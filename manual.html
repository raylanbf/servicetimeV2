Service Timer — Extensão Chrome MV3

Service Timer MV3

Extensão Chrome para controle de tempo por serviço, com ferramentas de produtividade para edição de conteúdo em plataformas LMS e rich text editors.

⏱Cronômetro

O painel lateral fica sempre visível enquanto você trabalha em outras abas, permitindo controlar o tempo sem interromper o fluxo de trabalho.

▶ Iniciar
Captura a URL da aba ativa e inicia o contador. O ícone da extensão fica verde.
⏸ Pausar / Retomar
Registra o horário de pausa e retorno automaticamente. O ícone fica laranja durante a pausa.
⏹ Finalizar
Abre o modal de comentário, salva o registro e exibe o resumo com duração total.
📌 Suspender
Pausa sem finalizar. O card fica na lista de suspensos e pode ser retomado a qualquer momento.
Múltiplos cards podem ficar suspensos simultaneamente. Para retomar um card suspenso, o atendimento atual deve estar finalizado ou suspenso primeiro.

O cronômetro também pausa automaticamente quando todas as janelas do Chrome são fechadas, registrando o horário de pausa no histórico do card.

Como funciona o envio

Os registros pendentes são enviados para o Google Apps Script, que:

  1. Busca ou cria automaticamente uma aba chamada "Service Timer" na planilha
  2. Cria cabeçalhos com fundo verde e linha congelada na primeira execução
  3. Verifica os IDs já existentes para evitar duplicatas
  4. Adiciona os registros novos como novas linhas

📋Checklist de publicação

Audita um ou vários cursos de uma vez, apontando pendências antes da publicação. Acesse pelo painel em 🎓 Canvas LMS → 📋 Checklist de publicação.

  1. Deixe qualquer página do Canvas aberta na aba ativa — é ela que autentica as consultas
  2. Cole os códigos dos cursos, um por linha. O botão + aba atual insere o curso que está aberto
  3. Ligue os verificadores opcionais que quiser
  4. Clique em ▶ Rodar verificações

Cada curso vira um card com um resumo — ✅ sem pendências · ⚠️ pontos de atenção · ❌ falha na consulta · – verificação desligada. Cards com pendência abrem sozinhos ao terminar; clique no cabeçalho para expandir ou recolher.

Escopo: apenas o que está nos módulos

As três verificações que olham páginas — Lorem Ipsum, Páginas sem vídeo e Páginas não publicadas — consideram somente as páginas vinculadas a algum módulo.

Uma página criada e depois retirada do módulo continua existindo no curso, mas deixa de ser auditada — rascunhos descartados não geram alarme falso.

Custo e limites

Os verificadores marcados como lentos exigem uma consulta por página do curso. Os cursos rodam em paralelo, então uma lista grande com tudo ligado dispara centenas de requisições de uma vez.

Rode em lotes de 3 a 5 cursos ao ligar os verificadores lentos. O Canvas limita a quantidade de consultas por usuário — ao estourar, as suas próprias requisições falham por alguns minutos. A extensão desacelera sozinha quando o limite se aproxima e repete as chamadas recusadas.

A validação de links é a mais demorada: ela dispara o job do Canvas e aguarda o resultado, o que leva até 3 minutos por curso, um curso de cada vez.

O checklist apenas lê o curso. A única exceção é a validação de links, que aciona o mesmo verificador nativo disponível nas configurações do Canvas — nada é publicado, alterado ou removido.
O resultado não é salvo: fechar o painel lateral durante a execução descarta a rodada.

📑Duplicar bloco na página

Copia um bloco HTML completo (div, seção, card etc.) para outra posição da mesma página, em dois cliques.

  1. Clique em 📑 Duplicar bloco na página — o cursor muda para copy e uma barra de instrução aparece no topo
  2. Passe o mouse sobre o bloco que deseja copiar — ele fica destacado em azul
  3. Use ↑ / ↓ para subir ou descer um nível na hierarquia HTML, se necessário
  4. Clique no bloco de origem — a seleção muda para a fase de destino (destaque em verde)
  5. Clique no bloco de destino — a cópia é inserida logo abaixo dele
A cópia remove automaticamente atributos id do HTML copiado, evitando âncoras duplicadas na página.

✋Reorganizar blocos (arrastar)

Reordena blocos HTML por arraste direto no editor. Ao ativar, o cursor muda para grab em todo o editor.

  1. Clique em ✋ Reorganizar blocos (arrastar) — barra de instrução aparece no topo e o cursor vira grab
  2. Passe o mouse sobre o bloco que deseja mover — ele fica destacado em azul
  3. Clique e arraste — cursor vira grabbing e o bloco fica semitransparente
  4. Uma linha verde aparece entre os elementos indicando onde o bloco vai cair
  5. Solte o mouse para confirmar o reposicionamento
O editor faz scroll automático enquanto você arrasta: a linha verde segue o destino e o editor rola suavemente para mostrar onde o elemento será inserido.

🗺Mapa de elementos

Abre um painel lateral (300 px) mostrando a hierarquia de elementos da página aberta no editor Canvas. Permite navegar, reordenar, duplicar e excluir blocos diretamente pelo painel.

Estrutura do painel

Cada linha representa um bloco classificado — com ícone, rótulo e prévia do texto. A indentação indica a profundidade na hierarquia HTML (até 4 níveis).

🖼 Banner
Identificado pelo id="banner"
🏷 Faixa
id="faixa" ou cor de fundo específica
▶ Vídeo
Elemento que contém um <iframe>
🃏 Card
id no padrão mod1, mod2… ou classe card
📝 Texto
Qualquer elemento com conteúdo textual não classificado
▦ Container / Coluna
Classes content-box, grid-row, col-*

Reordenar elementos com drag

  1. Mantenha a tecla M pressionada — cursor do painel e editor mudam para grab
  2. Clique e arraste uma linha do painel — ela fica semitransparente
  3. Uma linha verde aparece no painel indicando a posição destino
  4. Simultaneamente, uma linha verde com brilho é inserida no editor mostrando onde o bloco vai cair
  5. O editor faz scroll automático conforme você passa sobre linhas fora da área visível
  6. Solte o mouse para confirmar — tanto o painel quanto o editor são atualizados

Excluir elemento

  1. Clique em uma linha do painel (ou clique no elemento no editor) para selecioná-lo
  2. Pressione Del — o elemento é removido do editor e a linha some do painel
Del funciona independentemente do foco — tanto com o cursor no painel quanto dentro do editor Canvas.

Justificar texto campo editável

O TinyMCE do Canvas não traz o botão de justificar na barra — só em Formato → Alinhamento → Justificar. A extensão oferece três caminhos para o mesmo resultado:

CaminhoQuando usar
Botão na barra do editorInserido automaticamente na toolbar sempre que um editor do Canvas é aberto
Ctrl+Shift+JAtalho de teclado, com o cursor dentro do editor
📏 Justificar texto (Canvas)Menu de contexto, clicando com o botão direito dentro do campo
Não é preciso selecionar o texto: assim como os botões nativos de alinhamento, a ação vale para o parágrafo onde o cursor está. Alinhamentos herdados de <div> pai são limpos, para o Canvas não exibir "Direita" e "Justificado" marcados ao mesmo tempo.

🖊Marca-texto

Permite marcar visualmente trechos de texto em qualquer página web enquanto você trabalha — útil para controlar o que já foi copiado ou processado.

Como usar

  1. Mantenha a tecla A pressionada
  2. Selecione o texto desejado com o mouse normalmente
  3. Solte o mouse — o trecho fica destacado em amarelo
  4. Repita quantas vezes quiser na mesma página

✨Copia Inteligente

Ferramenta de cópia avançada para colar conteúdo em editores rich text como Canvas LMS, TinyMCE, CKEditor, Moodle e Bubble.io sem deixar lixo de HTML.

O que ela faz

🔤 Corrige mojibake
Detecta e corrige textos com encoding quebrado: JoÃ£o → João
🧹 Remove lixo HTML
Elimina class, id, style, data-*, scripts, iframes e tags vazias
🎨 Cor padronizada
Força #333333 em todos os parágrafos e listas, independente da cor original
📋 Lista unificada
Converte listas numeradas <ol> em listas com bullets <ul>
👁 Remove ocultos
Ignora elementos com display:none ou visibility:hidden
📝 Tags essenciais
Mantém apenas: <p> <br> <strong> <em> <ul> <li>

HTML gerado

Ao clicar em "Ver HTML" no editor após colar, o código estará assim:

<p style="color:#333333;">Texto com <strong>negrito</strong> e <em>itálico</em>.</p>

<ul style="color:#333333;">
<li>Primeiro item</li>
<li>Segundo item</li>
</ul>
Ao copiar, nenhum HTML fica visível. O conteúdo entra no clipboard nos dois formatos: text/html (para editores rich text) e text/plain (para campos de texto simples).

Como usar

  1. Selecione o texto na página
  2. Clique com o botão direito
  3. Escolha ✨ Copia Inteligente (para editores)
  4. Cole normalmente no editor com Ctrl+V
